# Monivra для Android: установка и обновление (тестовая версия)

Это тестовое приложение для вашего телефона. Оно работает без интернета, без аккаунта и ничего никуда не отправляет.

## Первая установка

1. Откройте файл `monivra-….apk`, который я прислала, на телефоне (из чата или из папки «Загрузки»).
2. Android может написать: «В целях безопасности установка приложений из неизвестных источников заблокирована». Это обычное предупреждение для приложений не из Google Play. Нажмите **Настройки**, включите **Разрешить из этого источника** (для того приложения, из которого открыли файл — Чат, Chrome или «Файлы») и вернитесь назад.
3. Нажмите **Установить**. Если Google Play Protect предложит проверить приложение — можно нажать **Установить всё равно**: приложение не из магазина, поэтому Android его не знает.
4. Откройте Monivra. Данные из веб-версии сами **не переносятся** (у приложения своё хранилище). Как перенести — ниже.

## Перенос данных из веб-версии (по желанию)

1. В веб-версии: **Ещё → Данные → Файл данных → Сохранить**. Получится файл `monivra-backup-….json`. Убедитесь, что он сохранился на телефоне (например, в «Загрузках»).
2. В приложении: **Ещё → Данные → Файл данных → Восстановить из файла**, выберите этот файл. Приложение покажет, что внутри, и спросит подтверждение. Пока вы не подтвердили, ничего не меняется. Повреждённый файл приложение откажется открывать, и ваши данные останутся как были.

## Обновление на новую сборку

1. Просто откройте новый `.apk` и нажмите **Установить** — «Обновить». Данные сохраняются, потому что у всех тестовых сборок одинаковое имя приложения (`app.monivra.finance`) и одинаковая подпись.
2. **Не удаляйте приложение перед обновлением.** При удалении Android стирает все его данные (внутренняя копия данных тоже в приложении и тоже стирается).
3. Если Android пишет «Приложение не установлено, так как конфликтует с существующим пакетом» — значит подпись новой сборки другая. Тогда **сначала** сохраните файл данных (**Ещё → Данные → Файл данных → Сохранить**) и убедитесь, что файл лежит на телефоне вне приложения (например, в «Загрузках» или отправьте себе в чат). Только после этого удалите приложение, установите новое и восстановите данные из файла.

## Резервная копия

Единственная копия, которая переживает удаление приложения или потерю телефона, — это файл данных, сохранённый вами вне приложения. Сохраняйте его время от времени: **Ещё → Данные → Файл данных → Сохранить** (или **Поделиться** — отправить себе в чат).

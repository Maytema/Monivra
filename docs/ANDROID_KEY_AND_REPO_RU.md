# Ключ подписи, закрытие репозитория и переход на тестовое приложение (для владельца)

Здесь нет секретов. Это пошаговая инструкция.

## 1. Что случилось с ключом
Старый тестовый ключ лежал в репозитории вместе с паролем, а репозиторий публичный. Считайте этот ключ
**скомпрометированным**: любой мог подписать APK тем же ключом. Закрытие репозитория это не отменяет.
Файл ключа убран из дальнейших коммитов, но остался в истории (историю мы не переписывали).
Старое приложение `app.monivra.finance` на вашем телефоне подписано этим ключом. Ставьте только APK,
который вам дал Claude и чей SHA-256 вы сверили.

## 2. Новое тестовое приложение
- Новый тестовый ID: `app.monivra.finance.dev`. Он ставится **рядом** со старым приложением и ничего не
  заменяет. Данные старого приложения остаются на месте.
- Данные автоматически не переносятся. Перенос через файл:
  1. В старом приложении: Ещё → Данные → Файл данных → Сохранить (или Поделиться). Файл `.json` положите
     вне приложения (Диск, почта себе, «Файлы»). Проверьте, что файл открывается и не пустой.
  2. Установите новое тестовое приложение (оно появится вторым значком «Monivra»).
  3. В новом: Ещё → Данные → Файл данных → Восстановить, выберите файл.
  4. Сверьте счета, операции и PIN. PIN нужно поставить заново, он не переносится.
  5. Старое приложение удаляйте **только после** того, как убедились, что в новом всё на месте и файл
     сохранён в двух местах.

## 3. Ключ для тестовых сборок: два варианта
Нужно четыре значения (в GitHub Secrets) и офлайн-копия ключа у вас. Ключ, который есть только в
Secrets или на сервере сборки, при потере пропадает.

**Вариант А (проще).** Claude создаёт ключ здесь и присылает вам файлы. Минус: ключ и пароль проходят
через этот чат. Для тестового приложения с отдельным ID это допустимый риск, для боевого ключа Google Play
так делать нельзя.

**Вариант Б (надёжнее).** Вы создаёте ключ на компьютере:
`bash android-app/scripts/make-test-key.sh ~/monivra-keys`
Скрипт ничего не выводит, кроме отпечатка. Он создаёт файл ключа и `github-secrets.txt`.

После любого варианта:
1. GitHub → репозиторий → Settings → Secrets and variables → Actions → New repository secret.
2. Создайте четыре секрета с точными именами: `MONIVRA_KEYSTORE_B64`, `MONIVRA_KEYSTORE_PASSWORD`,
   `MONIVRA_KEY_ALIAS`, `MONIVRA_KEY_PASSWORD` и значениями из `github-secrets.txt`.
3. Сохраните папку с ключом в двух местах вне телефона (например, USB-накопитель и облако с паролем).
4. Удалите `github-secrets.txt` из общих мест.
5. Напишите Claude «ключ задан». Только тогда будет собран APK для установки.

## 4. Закрыть репозиторий (приватный)
Сейчас репозиторий публичный. Перед закрытием учтите: **сайт на GitHub Pages может отключиться**, если у
вашего аккаунта бесплатный тариф (Pages для приватных репозиториев требует платный тариф). Claude это
не меняет, пока вы не решите.
Если решили: Settings → General → Danger Zone → Change visibility → Make private.
Закрытие не отзывает ранее утёкший ключ (см. пункт 1) и не стирает копии, уже сделанные другими.

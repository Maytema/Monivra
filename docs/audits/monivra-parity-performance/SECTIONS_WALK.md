# Обход разделов в обеих версиях (одинаковые касания, без выполнения действий)

Как проверено: `tools/audit/compare.mjs` (`tour()`), одинаковые пути в двух версиях на одном эмуляторе, после
загрузки одного файла данных. Каждый шаг — касание надписи или долгое нажатие, затем скриншот и дерево экрана
(`audit-results/runs/<N>/{old,rn}/tour/`). Ничего не сохраняется и не удаляется. Прогон 12 (14.11): 36
экранов старого, 41 нового; часть путей прервалась из-за самого обхода (название периода сменилось после
замеров, надписи на кнопках-плитках склеены с суммой) — исправлено для следующего прогона.

Классы: **СОВПАДАЕТ** — путь есть, экран тот же по составу и виду; **ПО ЗАПРОСУ** — отличие сделано по вашим
снимкам/видео; **ИСПРАВЛЕНО** — отличие было, приведено к браузерной (коммит в `rn-migration`); **ОСТАЛОСЬ** —
мелкое отличие, не исправлено.

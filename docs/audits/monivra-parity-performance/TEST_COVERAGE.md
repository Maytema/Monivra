## Чего не хватает (по убыванию пользы)

1. **Одни и те же сценарии в обеих версиях** — сейчас общий сценарий покрывает запуск, восстановление,
   вкладки, прокрутку, свайпы, список валют. Нужны: создание/правка/удаление операции, перевод, долг,
   бюджет, запланированный платёж, поиск, фильтры, импорт CSV, экспорт, PIN — с одинаковым итогом в обеих
   версиях (суммы на экране) и скриншотами для визуальной сверки (BL-P1-05).
2. **Пороги скорости в CI** — замер есть, но сборка не падает, если стало медленнее. Предложение: хранить
   медиану трёх прогонов и падать при ухудшении > 25 % по «settle» для 5 движений (BL-P1-04).
3. **Кадр в середине броска для всех длинных списков** (валюты, операции, курсы) с автоматическим поиском
   пустых полос (доля однотонных строк на скриншоте).
4. **Файл блокировки зависимостей** `mobile/package-lock.json` — без него две сборки одного коммита могут
   получить разные версии пакетов, и сравнение «до/после» не чистое (BL-P1-01).
5. **Проверки на телефоне** — камера, отпечаток, уведомления по времени, фоновая проводка, курсы из сети;
   автоматизировать в облаке нельзя, нужен короткий чек-лист для владельца (BL-P2-06).
6. Тёмная тема и русский язык в эмуляторном обходе (сейчас только светлая тема, английский).

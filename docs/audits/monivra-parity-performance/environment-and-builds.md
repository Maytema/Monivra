## Эмулятор (один и тот же для обеих версий)

GitHub Actions, `reactivecircus/android-emulator-runner@v2`: Android 14 (API 34), `google_apis`, x86_64, профиль
`pixel_6` (1080×2400), 4 ГБ ОЗУ, KVM, графика **программная** (`swiftshader_indirect`), анимации включены.
Обе версии ставятся на один эмулятор в одном прогоне (`tools/audit/run-compare.sh`), с одним файлом данных:
3000 операций за 18 месяцев, генератор с фиксированным зерном (`mobile/scripts/perf-data.mjs`).

Ограничения сравнения:
- Программная графика делает каждый кадр медленнее, чем на телефоне: абсолютные числа кадров выше реальных;
  сравнивать стоит версии между собой, а не с 16,7 мс телефона.
- Телефона владельца в проверке нет: всё, что зависит от конкретного устройства, помечено «нужна проверка на телефоне».
- Время включает запуск инструмента `adb shell input` (около 100–300 мс) — одинаково для обеих версий.

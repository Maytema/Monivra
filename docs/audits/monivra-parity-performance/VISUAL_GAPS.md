# Визуальные расхождения

Как проверено (размеры в пикселях снимка 1080×2400): обе версии на **одном** эмуляторе (Pixel 6, 1080×2400, Android 14), одни и те же данные
(3000 операций), один и тот же месяц — скриншоты прогона аудита (`audit-results/runs/<N>/old/*.png` и
`rn/*.png`, список в `SCREENSHOTS.md`). Сравнены 6 экранов: Счета, Категории, Операции, Статистика (верх),
Форматирование, Выбор валюты. Остальные экраны визуально **не сравнивались** в этом аудите (их проверяли по
одному в прошлых сборках — см. `docs/architecture/MIGRATION_STATUS.md`).

Многие отличия сделаны **намеренно** по эталонным снимкам владельца (`catalog/`, коды CT…/OP…), а не по
браузерной версии — это видно по сообщениям коммитов. Новое задание говорит «1:1 как браузерная версия»,

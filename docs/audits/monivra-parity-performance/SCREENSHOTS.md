# Скриншоты

Лежат в ветке `audit-results`, папка `runs/<N>/old/` (старое приложение) и `runs/<N>/rn/` (новое) — один
эмулятор, одни данные. К каждому `.png` есть `.xml` — дерево экрана (тексты и границы элементов).

| Файл | Что на нём |
|---|---|
| `00-restore-page` | страница восстановления после выбора файла данных |
| `01-after-restore` | сразу после «Заменить данные» |
| `02-started` | Счета после холодного запуска с данными |
| `03-operations` | Операции, текущий месяц |
| `04-operations-after-swipes` | Операции после 3 свайпов назад и 3 вперёд |
| `05-categories` | Категории, текущий месяц |
| `06-statistics` | Статистика, верх страницы |
| `07-formatting` | Настройки → Форматирование |
| `08-currency-list` | Выбор валюты сразу после открытия |
| `09-currency-list-flicked` | после 8 быстрых бросков вниз |
| `10-currency-list-mid-fling` | **в середине** броска вниз (с прогона 5) — видны ли пустые строки |
| `11-currency-list-mid-fling-up` | в середине броска вверх (с прогона 5) |

Скачать один файл: `git fetch origin audit-results && git show origin/audit-results:runs/8/rn/03-operations.png > rn-03.png`.

Основной прогон — **8** (обе версии с данными). Прогоны 4–7 — промежуточные, ошибки их замера описаны в
PERFORMANCE_ROOT_CAUSES.md. В прогоне 7 старое приложение без данных (закрылось после окна выбора файла).

# Decisions forced by the browser

Where a rule exists only because the browser requires it, it is listed here, so that a native version
(Android, iOS) replaces it instead of copying it. The code that carries each is named.

| Area                        | What the browser forces                                                                                                                                                                                                                                                                                                           | Where                                                                                         | Native version                                                                                 |
| --------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------- |
| Sharing a file              | `navigator.share` may start only soon after a tap (transient activation, a few seconds). A PDF that takes longer to prepare loses the tap, so the person is asked for one more tap in a dialog that shares at once (a fresh tap). Preparing is done first and sharing last; a prepared file is kept, so the second tap is instant | `platform/files.js` `shareFile`, `ui/file-actions.js` `shareDelivery`, `data/report-cache.js` | Share the file from a background task with the system share intent: no tap rule, no second tap |
| Types that can be shared    | Browsers share only some file types (`canShare`); JSON is often refused. Then the person is told, and offered Save as a separate choice; nothing is saved on its own, and the file stays a real `.json`                                                                                                                           | same                                                                                          | Any file type can be shared                                                                    |
| Share sheet never answers   | Some browsers leave the promise open after an app was picked. Only a tap within 1.5 s of the last one counts as a repeat                                                                                                                                                                                                          | `shareFile`                                                                                   | Not applicable                                                                                 |
| Printing                    | The print dialog is opened from a hidden frame with the page pictures; there is no print job API, so the PDF printed is made of images. One frame at most                                                                                                                                                                         | `platform/files.js` `printPages`                                                              | Print the vector PDF through the system print service                                          |
| Saving                      | A save is a download of an object URL into the downloads folder; the browser decides the folder and the name on a clash                                                                                                                                                                                                           | `saveFile`                                                                                    | Write through the storage access framework to a folder the person picks                        |
| Scheduled payments          | Nothing runs while the page is closed: due payments are posted when the application opens, comes back to the front, and every minute while open. They keep their own date and time                                                                                                                                                | `app/startup.js`, `domain/scheduled.js`                                                       | A background job or an exact alarm                                                             |
| Reminders and notifications | Permission is asked from a tap; closed pages cannot notify; `sw.js` is minimal                                                                                                                                                                                                                                                    | `domain/reminders.js`, `platform/notify.js`                                                   | Local notifications scheduled by the system                                                    |
| PIN and biometrics          | A salted hash in local storage protects the screen only, not the data; there is no secure hardware                                                                                                                                                                                                                                | `platform/pin.js`, `platform/biometric.js`                                                    | Keystore or Keychain with the system biometric prompt, and encrypted storage                   |
| Storage                     | All data is one JSON document in `localStorage` (about 5 MB, may be cleared by the browser). Backups inside the application are part of it                                                                                                                                                                                        | `data/storage.js`                                                                             | A database file in the app's private folder                                                    |
| Prepared exports            | A few prepared reports are kept in memory, never on the device, because page pictures are large                                                                                                                                                                                                                                   | `data/report-cache.js`                                                                        | Files in the app cache folder                                                                  |
| File choosers               | Opening a file needs a tap and returns a copy                                                                                                                                                                                                                                                                                     | `pickFile`                                                                                    | Document picker                                                                                |

## What the Android shell replaces (first test APK, branch `android-first-apk`)

The browser rules above stay in force in a browser. Inside the Android application the same functions
take another path (`platform/native.js` tells which); the full description is in `ANDROID.md`.

| Area                        | In the Android application                                                                                                                                                                                                    | Code                                                                 |
| --------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------- |
| Sharing a file              | System share sheet with the file attached by a content address (FileProvider). No tap rule, so no "ready to share" second tap. Any type, including `.json`. "Shared" means the sheet was opened: Android does not say more    | `platform/files.js` `shareFile`, `MonivraNativePlugin.shareDocument` |
| Saving                      | System "save as" screen (storage access framework): the person picks the place and the name; nothing is written if the screen is closed, and no storage permission exists                                                     | `saveFile`, `MonivraNativePlugin.saveDocument`                       |
| Printing                    | System print service, given the PDF itself (text stays text); a chosen page range is drawn as pictures because the print service wants exactly those pages                                                                    | `printPages`, `PdfPrintAdapter`                                      |
| File choosers               | The WebView file chooser opens the system document picker; no permission                                                                                                                                                      | `pickFile` (unchanged)                                               |
| Scheduled payments          | **Unchanged on purpose**: a payment is posted when the application opens, returns to the front, and every minute while open, with its own date and time. Nothing posts money while the application is closed (see ANDROID.md) | `app/startup.js`, `domain/scheduled.js`                              |
| Reminders and notifications | Reminders for the next 60 days are handed to Android as local notifications (inexact, may be minutes late; survive a restart of the phone). The application shows in-app only what Android was not asked to deliver           | `domain/reminder-plan.js`, `app/reminders.js`, `platform/notify.js`  |
| PIN                         | The hash is kept in a file encrypted with a Keystore key; the data holds only a marker `{v:2,native:true,length}`. If the system cannot give the hash back, the lock is turned off with a notice instead of locking out       | `platform/secure-pin.js`, `app/native-pin.js`, `SecureStore`         |
| Biometrics                  | System prompt (androidx.biometric, class 2 "weak" or better) that opens the lock screen; the PIN stays the fallback. Hidden where the phone cannot do it. Not encryption, not an account                                      | `platform/biometric.js`, `screens/more/lock.js`                      |
| Storage                     | Still the one JSON document in the WebView's `localStorage` (same ~5M characters limit), plus a second checked copy in the private files used only if the first is gone                                                       | `data/storage.js`, `platform/native-sync.js`, `DataMirror`           |
| Back, bars, recents         | Back steps back through layers and pages and minimises at the first screen; bars follow the theme; "Hide preview" also sets FLAG_SECURE                                                                                       | `platform/lifecycle.js`, `platform/system-bars.js`, `MainActivity`   |
| Prepared exports            | Unchanged (in memory, one per choice of the export)                                                                                                                                                                           | `data/report-cache.js`                                               |

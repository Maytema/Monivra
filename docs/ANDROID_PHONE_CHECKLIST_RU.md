# Monivra для Android: проверка на телефоне

Что делать и что должно получиться. Всё, чего я не могла проверить на настоящем телефоне, отмечено здесь. Эмулятор Android в сборке проверил основу (установку, запуск, сохранение данных, PIN, системные экраны, напоминание, обновление); отпечаток пальца, живую печать на принтер и поведение именно вашей прошивки может проверить только телефон.

Отмечайте: ✅ получилось, ❌ не получилось (и что именно произошло).

## 1. Установка и запуск
- [ ] Установить `.apk` по инструкции (`ANDROID_INSTALL_RU.md`). Ожидается: приложение с иконкой Monivra в списке приложений; в Android 13+ иконка может подкрашиваться в цвет темы.
- [ ] Открыть. Ожидается: заставка с символом Monivra, затем экран приветствия (или ваши данные, если уже были).
- [ ] Включить режим полёта и открыть приложение. Ожидается: работает так же, интернет не нужен.

## 2. Данные не пропадают
- [ ] Создать два счёта, несколько операций, перевод, кредитную карту с лимитом.
- [ ] Смахнуть приложение из списка недавних, открыть снова. Ожидается: всё на месте.
- [ ] Перезагрузить телефон, открыть. Ожидается: всё на месте.

## 3. Файлы
- [ ] **Ещё → Данные → Файл данных → Сохранить.** Ожидается: системное окно «Сохранить как», вы выбираете папку; после «Сохранить» — сообщение «Файл сохранён». Если нажать «Назад» в этом окне — сообщения нет и ничего не записано.
- [ ] **Поделиться.** Ожидается: системное окно выбора приложения, с файлом `.json`. Быстро нажать два-три раза — окно открывается один раз.
- [ ] **Экспорт данных → PDF → Предпросмотр → Сохранить / Поделиться / Печать.** Ожидается: PDF открывается в предпросмотре; «Сохранить» — окно выбора места; «Поделиться» — окно выбора приложения; «Печать» — системное окно печати с документом (на «Печать в PDF» можно получить файл, в нём выделяется и ищется текст).
- [ ] Экспорт CSV и импорт CSV из «Загрузок». Ожидается: файл выбирается системным окном; импорт показывает таблицу и спрашивает подтверждение.
- [ ] Восстановить из файла данных (веб-версии). Ожидается: предпросмотр, затем подтверждение. Подсунуть «битый» файл (например, обрезанный `.json`): приложение отказывается, данные не меняются.

## 4. Блокировка и отпечаток
- [ ] **Настройки → Безопасность → PIN-код**: задать PIN. Выйти из приложения и вернуться (после «Блокировать после выхода»). Ожидается: экран PIN.
- [ ] В настройках телефона должен быть добавлен отпечаток или лицо. Тогда в **Безопасность** появится «Разблокировка отпечатком или лицом». Включить (нужно один раз приложить палец). Ожидается: при блокировке сразу окно системной проверки; успех — вход; «Ввести PIN» или отмена — клавиатура PIN работает.
- [ ] Без настроенного отпечатка пункт показывает «Не настроено на этом телефоне» и не включается.
- [ ] Приложение не шифрует данные ни PIN-кодом, ни отпечатком: блокировка только закрывает экран. Это сказано и на экране настроек.
- [ ] **Скрыть предпросмотр** (Настройки → Конфиденциальность): включить, свернуть приложение. Ожидается: в списке недавних вместо содержимого пустой экран (и снимки экрана при этом недоступны).

## 5. Уведомления
- [ ] **Настройки → Уведомления**: включить. Ожидается: только сейчас Android спрашивает разрешение. Отказ не ломает приложение: напоминания будут внутри приложения.
- [ ] Создать плановый платёж на ближайшие 5 минут с напоминанием за пару минут до платежа. Закрыть приложение (смахнуть). Ожидается: приходит уведомление «Плановый платёж». Android может задержать его на несколько минут для экономии заряда (это нормально, точных будильников приложение не просит).
- [ ] Открыть приложение после времени платежа. Ожидается: платёж появился в операциях **один раз**, со своими датой и временем (не временем открытия).
- [ ] Перезагрузить телефон при запланированном напоминании. Ожидается: напоминание всё равно приходит (после перезагрузки Android восстанавливает их; но если телефон не открывали, платёж появится только при открытии).

## 6. Кнопка «Назад», вид
- [ ] Открыть любую страницу или окно и нажать «Назад» (кнопка или жест). Ожидается: закрывается окно/страница; на первом экране приложение сворачивается.
- [ ] Повернуть телефон. Ожидается: ничего не теряется, нижняя панель на месте.
- [ ] Тёмная и светлая темы, русский и английский язык. Ожидается: цвета панелей сверху и снизу совпадают с экраном; тексты не обрезаются.
- [ ] Открыть клавиатуру в поле ввода. Ожидается: поле не закрыто клавиатурой.

## 7. Обновление
- [ ] Когда пришлю новую сборку: установить поверх (не удаляя). Ожидается: данные и PIN на месте.

Если что-то не получилось — пришлите, что вы нажимали и что увидели (скриншот помогает), модель телефона и версию Android.

## Cache timings (headless Chromium, sample data, one run)

First Preview 165 ms, second (prepared) 40 ms. A 34-page report builds in about 670 ms. A change of a section, of the data or of the language is a miss; counted by `cacheStats` in the scenario.

## Limits and what was not tested on a device

- Browser mocks stand in for `navigator.share`/`canShare` and for the print dialog. A real Android Chrome was not available.
- A share started after a long preparation may be refused by the browser (needs a fresh tap). The person is told once; the next tap uses the prepared file, so it cannot loop.

### Manual Android checklist

1. Export > Financial summary > Share: the sheet opens with a real PDF (a short wait the first time, instant the second).
2. Tap Print five times fast: one print dialog; cancel it; tap again: one dialog.
3. Tap Print, press Back at once: no dialog appears later.
4. Data file > Share: the file is a real `.json`; if the browser refuses, the message offers Save, nothing downloads on its own.
5. Export > CSV: turn every field off and on: rows keep their size.
6. Restore a file from another device with a clashing category: Merge works, the category is added separately.
7. Delete my data: both dialogs are short, scroll if needed, and "Create a backup first" is on only for partial deletion.

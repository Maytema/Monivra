# 0002 — Which reference wins

**Decision.** The set of windows, what they do and the money rules come from the first application (its
code and its running windows; inventory with `tools/tour/crawl-old.mjs`). The look comes from the
owner's references: `catalog/screens/`, films and screenshots the owner sends (the original product
the first application was modelled on). Where the look of the first application differs from those, the
owner's reference wins. An explicit decision of the owner (records below) wins over both.

**Why.** The owner asks for the first application's full functionality ("всю информацию которая в старом
есть полностью перенести") and showed the original product's screens as the look to reach (the account
form film, the Support screen).

**Examples.** Account form, "Select type" sheet, "Customize icon": from the owner's film. Select currency as a
full page, the "Take from / Add to / To account" pickers before the calculator, Profile and Subscription
pages: from the first application.

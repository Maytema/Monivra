The stand: the real screens (features/, ui/) in a browser, on stubs for React Native, with the counters of what a swipe builds.

    node gen-ledger.ts 3000 && node build.mjs && node run.mjs
   SRC=/path/to/another/src node build.mjs   # another checkout

Needs esbuild, playwright and Chrome (/opt/npm-tools). It shows how many pages, lists and rows a swipe mounts and draws, not the speed on a phone.
